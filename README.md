# Python Revenue Maximization

A Python (Jupyter Notebook) group project (Group 5) analysing a student dataset with the aim of revenue maximization.

## Files
| File | Description |
|---|---|
| `Revenue_max_grp_5.ipynb` | Analysis notebook |
| `final_student_dataset.parquet` | Final cleaned dataset used by the notebook (~51 MB) |
| `.gitignore` | Git ignore rules |

## Run locally
```bash
git clone https://github.com/RaviPSingh-26/Python-Revenue-Maximization.git
cd Python-Revenue-Maximization
pip install jupyter pandas pyarrow
jupyter notebook Revenue_max_grp_5.ipynb
```
`pyarrow` is needed to read the `.parquet` file. Install any other libraries the notebook imports.
